# web ios-standby 

Although the iOS standby feature is updated at IOS 17, not all iPhone can use 'always turn on' mode for the feature. only after 14 series can do that

For that reason, I copied the feature and deployed it on web. 

All iPhones now can turn on the feature everytime :)
